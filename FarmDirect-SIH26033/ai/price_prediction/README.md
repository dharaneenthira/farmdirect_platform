# AI Price Prediction Module

## Purpose
Predict future crop prices at the regional and mandi level using historical market data, seasonal trends, weather forecasts, and arrival volumes.

## Planned Stack
- Python 3.10+
- Pandas & NumPy (Data manipulation & feature engineering)
- Scikit-Learn (Random Forest, Gradient Boosting, XGBoost Regression models)

## Planned Inputs
- Historical Mandi Price Data (Agmarknet datasets)
- Rainfall & temperature trends
- Crop harvest schedule and regional yield estimates

## Planned Outputs
- 7-day, 15-day, and 30-day price trend forecasts with confidence intervals.
- Optimal selling window recommendations for farmers.
