# AI Price & Activity Anomaly Detection Module

## Purpose
Detect unnatural price manipulations, suspicious bidding collusion, hoarding indicators, and fake listing behavior to maintain marketplace integrity.

## Planned Stack
- Python 3.10+
- Isolation Forest & One-Class SVM anomaly detectors
- Statistical Z-score outlier filters

## Planned Signals
- Sudden deviation of listing prices from regional benchmark averages.
- Unusual order cancellation rates or repeated unfulfilled bids.
- Duplicate imagery / suspicious seller account clusters.
