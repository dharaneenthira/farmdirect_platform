# AI Smart Farmer-Buyer Matching Module

## Purpose
Intelligently pair farmers selling produce with compatible buyers based on location proximity, quantity constraints, target price, produce grade, and preferred delivery windows.

## Planned Stack
- Python 3.10+
- Multi-objective optimization algorithms
- Geodesic distance matrices (Haversine formula / routing APIs)

## Features
- Full order matching & partial order matching (combining produce from multiple smallholder farmers to fulfill large buyer requirements).
- Logistics cost minimization scoring.
